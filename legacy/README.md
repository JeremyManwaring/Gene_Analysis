# Retired heuristic code

This directory preserves earlier scripts and tests for audit. They are not part of the installed package, the active pipeline, or the verification suite. Their old outputs were not clinically calibrated probabilities. Direct script execution stops with a message directing users to `gene-analysis`.

`root/` contains the former outer checkout scripts. `nested/` contains the earlier working copy, including prior local edits. Its former Git metadata and the pre-migration parent index are backed up locally under `.git/local-migration-backup/` and are not published.

Do not use legacy reports or calculations for medical decisions. The new pipeline does not rewrite historical result files. The repository's previous tracked personal reports were removed from the current index and preserved on disk; older Git commits still retain whatever was already committed.
