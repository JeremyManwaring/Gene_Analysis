# Gene Analysis package

Use the [repository README](../README.md) for setup, supported inputs and scientific scope.

```sh
python -m Gene_Analysis demo
python -m Gene_Analysis analyze "/path/to/your/dna.txt"
```

The active pipeline annotates measured variants against explicit public evidence. It does not return clinically validated disease probabilities. Old heuristic scripts are archived in [`legacy/`](../legacy/).
